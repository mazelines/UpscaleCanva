# 웹 사용 안내

최초 설치를 마친 뒤 프로젝트 루트의 `Start-Web.cmd`를 더블클릭하세요. 기본 접속 주소는 **http://127.0.0.1:7860** 입니다. 웹 화면 이름은 ARION Upscale Studio이며, 이미지 처리는 서버를 실행한 PC의 NVIDIA GPU에서 수행합니다.

## 사용 방법

1. PNG/JPEG/WebP 이미지를 선택하거나 등록 영역으로 드래그합니다. 파일당 최대 32MB, 1,600만 픽셀, 한 번에 최대 8장을 지원합니다.
2. 클립보드 이미지는 `Ctrl+V` 또는 등록 영역의 우클릭 메뉴로 추가합니다. 메뉴에서 직접 읽는 기능은 브라우저의 클립보드 지원과 접근 권한에 따라 달라지며, 사용할 수 없으면 단축키 안내가 나옵니다.
3. 기본 2배, 애니메이션 선화, 두 모델 비교 중 선택하고 **AI 2배 확대하기**를 누릅니다.
4. 완료된 작업을 선택해 원본과 결과를 비교합니다. 확대·이동은 양쪽에 함께 적용됩니다.
5. **PNG 다운로드** 또는 **클립보드 복사**로 결과를 가져옵니다.

브라우저를 닫아도 업로드가 완료된 작업은 서버에서 계속 처리합니다. 원본과 결과는 자동 삭제하지 않습니다. 작업 내역의 삭제 버튼은 내역만 지우며 원본·결과 파일은 남깁니다.

GPU 작업은 하나씩 처리하며 실행 중인 작업을 포함해 최대 8개까지 대기할 수 있습니다. 저장 공간이 5GB 미만이면 새 업로드를 거부합니다. 서버 재시작 시 미완료 작업은 중단 상태로 표시되므로 다시 등록해야 합니다.

## 시작과 종료

프로젝트 루트에서 실행합니다.

```powershell
.\Start-Web.cmd                      # CUDA 확인 후 백그라운드 시작
.\Start-Web.cmd --no-pause           # 호출 후 키 입력을 기다리지 않음
.\scripts\Start-Web.ps1 -Foreground  # 현재 터미널에서 서버 로그 확인
.\scripts\Show-WebAccess.ps1         # 설정된 접속 주소 확인
.\scripts\Stop-Web.ps1               # 신규 요청 중지, 진행 중 GPU 작업은 마저 처리
```

백그라운드 시작에 성공하면 CMD 창을 닫아도 서버는 계속 동작합니다. 시작에 실패하면 표시된 오류와 `logs/web-server.log`를 확인하세요. 현재 설치에서는 Node.js가 PATH에 있어야 하고 프로젝트 `.venv`와 chaiNNer 구성이 필요합니다.

## 로컬 설정과 Tailscale

첫 서버 실행 시 `runtime/web/config.json`을 다음 기본값으로 생성합니다.

```json
{
  "port": 7860,
  "hosts": ["127.0.0.1"]
}
```

이 설정 파일은 Git에서 제외합니다. 기존 설정이 있으면 그대로 사용합니다. 새 클론은 각 PC의 로컬 주소에서만 수신합니다.

다른 기기에서도 접속하려면 서버 PC의 실제 Tailscale IPv4 주소를 `hosts`에 추가한 뒤 서버를 다시 시작하세요. 같은 개인 네트워크의 연결·접근 정책·방화벽 설정은 사용 환경에 맞게 준비해야 합니다. 설정에 넣은 주소는 서버 PC에 실제로 할당되어 있어야 합니다.

앱 자체 로그인은 없습니다. 서버는 로컬/Tailscale 주소만 허용하며 Host·Origin 검사와 요청 헤더 검증을 적용합니다. `0.0.0.0` 수신은 허용하지 않습니다. Tailscale, 방화벽, 외부 공개 설정을 자동으로 변경하지 않습니다.

## 선택적인 윈도우 부팅 자동 실행

수동 실행을 확인한 뒤 관리자 PowerShell에서 다음 명령으로 예약 작업을 등록할 수 있습니다. 새 클론에 자동 등록되지는 않습니다.

```powershell
.\scripts\Enable-WebStartup.ps1
Get-ScheduledTaskInfo -TaskName 'ARION Upscaler Web'
```

작업은 부팅 후 30초 뒤 시작하고, 설정된 네트워크 주소와 CUDA 준비가 늦으면 재시도합니다. 암호를 저장하지 않는 S4U 로그온을 사용하며 등록 당시의 프로젝트·Node.js 경로를 참조합니다. 설치 폴더나 Node.js 위치를 옮긴 경우 등록을 갱신해야 합니다. 시작 기록은 `logs/web-startup.log`에 저장합니다.

자동 실행 해제는 관리자 PowerShell에서 수행합니다. 현재 실행 중인 서버는 별도로 종료해야 합니다.

```powershell
Unregister-ScheduledTask -TaskName 'ARION Upscaler Web' -Confirm:$false
```

## 데이터 저장 위치

| 위치 | 내용 |
|---|---|
| `input/web/<작업 ID>/` | 업로드 원본 및 미리보기 |
| `output/web/<작업 ID>/` | 확대 PNG와 추론 기록 |
| `runtime/web/jobs/` | 작업 상태와 Python 실행 로그 |
| `runtime/web/config.json` | PC별 수신 주소와 포트 |
| `logs/web-server.log` | 서버 시작 및 오류 기록 |
| `logs/web-startup.log` | 부팅 자동 실행 기록 |

위 경로의 데이터는 Git에 포함되지 않습니다. 저장소를 업데이트해도 개인 작업 파일과 로컬 설정은 유지됩니다.
